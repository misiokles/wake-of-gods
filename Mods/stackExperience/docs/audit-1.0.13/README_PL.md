# Dokumentacja audytu

Raport PDF, CSV (UTF-8 BOM, średnik), statystyki JSON oraz logi końcowe znajdują się w tym katalogu. Pliki C++ są kodem samodzielnych scenariuszy testowych, nie modyfikacjami silnika. Skrypty uruchomieniowe odnoszą się do ścieżek środowiska roboczego i wymagają odtworzenia dostarczonego środowiska VCMI, bibliotek oraz obiektów testowych; nie stanowią przenośnego instalatora. Opcjonalne podmody z brakującymi zależnościami nie były aktywne.

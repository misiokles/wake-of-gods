# Spell Book 0.1.3 — source and native audit

Sources: classic 51 wog - spell book.erm/ert (s.zip, s_classics.zip) and GrayFace script027.erm/ert (same ERT records). Script051 in GrayFace is Enhanced Commanders, not Spell Book. Original dialogue records 127000–127003 restored in English, with Polish counterparts. Records 127004–127008 are internal debug errors, not player messages.

All 94 reward branches remain mechanically unchanged. Native checks covered all 100 dice values and 32 combinations of skills and book ownership; each yielded exactly one applicable reward with correct tier, level distribution, book grant flag, removal flag and substituted spell names. 1174 of the 3200 checked branches contained repeated spell draws (not an independent statistical sample). VCMI filters map-allowed, non-special spells and independently draws each entry. ERM requests exclusions, but no robust JSON fallback was established for a map with too few eligible spells; repetitions are retained. The original comment says no movement spells, but the ERM helper actually allows adventure spells unless disabled/banned. Native Wisdom and already-known spell rules are retained. A map with no eligible spells at a requested level can cause the engine to return NONE; full handling has not been verified. Actual pickup, removal, AI, GUI, and save/load remain to be tested. Dialog icons for heroes without a spellbook may initially mark spells as unlearnable because the window precedes the artifact grant. No engine edits.
